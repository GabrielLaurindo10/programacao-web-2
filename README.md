PROGRAMAÇÃO WEB 2

Sobre a disciplina:
Este repositório foi criado para organizar as atividades e exercícios desenvolvidos durante a disciplina de Programação Web 2.

Objetivo:
O objetivo deste repositório é armazenar e organizar os códigos, respostas e demais atividades realizadas durante a disciplina, facilitando o acompanhamento do desenvolvimento dos conteúdos estudados.

Organização:
As atividades serão organizadas em pastas separadas dentro do repositório. Cada atividade poderá possuir seus próprios arquivos de respostas e códigos, conforme as orientações fornecidas pelo professor.

Atividades:
As atividades da disciplina serão adicionadas ao repositório conforme forem sendo solicitadas e desenvolvidas ao longo do semestre.
